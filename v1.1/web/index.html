1. 绝不越权：Agent 只能提议，不能擅改

通用大模型直接生成 Word 文档容易产生文本幻觉并破坏公式。在 Paper Setting 中，Agent 只能生成审查计划，最终补丁必须在 Web 界面由作者人工审批。

2. 零隐私泄露：100% 本地隔离运行

服务绑定 127.0.0.1，排版引擎与 AST 运算完全在本地单机沙箱中进行，未发表的学术成果绝对不会上传至第三方服务器。

3. 机器可读的可审计差量（Diff）

每次排版均保留只读原件，并生成段落级别的 .audit.json 清单。每一项字号、行距、页眉页脚均具备唯一 Operation ID，提供完整的科研可复现性。

工作目录可在 PAPER_SETTING_ALLOWED_INPUT_ROOTS 中配置。
