# Paper Setting v1.1：双视图学术论文智能排版工作台

本项目为 Paper Setting v1.1 **「默认极简离线 vs 手动详细Agent智排」** 双视图学术排版系统工程实现与可运行 MVP。

---

## 核心设计哲学与双视图架构

针对学术论文排版场景，明确划分两个核心视图：

### 1. 默认视图：极简排版 (Minimalist Local Engine)
- **定位**：解决 90% 的通用排版合规需求（字号、字体、行距、页边距、标题分级、首行缩进）。
- **特性**：
  - **100% 纯本地离线纯算**，断网可用，坚决不连接外部网络与大模型。
  - **绝对保障论文隐私安全**：未发表初稿绝不外发、绝不上云、0 Token 消耗，彻底消除查重与泄密焦虑。
  - **4 步直觉流**：传稿 $\rightarrow$ 选标准/模板 $\rightarrow$ 本地一键渲染 $\rightarrow$ 导出 DOCX。

### 2. 手动选择：详细与 Agent 智排 (Detailed & Agent-Assisted)
- **定位**：攻坚 10% 的复杂排版疑难杂症。
- **特性**：
  - **引入 Agent 深度语义理解**：针对非标格式文本自动提炼规则包。
  - **深度 OOXML 结构重构**：正文引注智能转真脚注、动态图表交叉引用修复（`SEQ`/`REF`）、OMML 公式多级对齐。
  - **可审计与人机协同**：段落级修改前后 Diff 对比、手动勾选/撤销。
  - **AI 二次盲审质检报告**：输出详细的问题建议清单（如参考文献年份缺失提醒）。

## 快速启动可运行 MVP

### 1. 一键启动服务与工作台

在工作区根目录下执行：

```bash
.venv/bin/python v1.1/run.py
```

服务将自动启动并在浏览器中打开：
`http://127.0.0.1:8765`

### 2. 运行 v1.1 自动化测试套件

```bash
.venv/bin/pytest v1.1/tests/ -v
```

## 完整业务流程验证指南

### 路径 A：极简 4 步直觉排版流 (默认)
1. **载入文稿**：点击【📄 没有文件？一键载入演示论文初稿】，系统即刻生成包含格式缺陷的仿真学术论文，并在沙箱中完成结构拓扑识别。
2. **选择规范**：点击【下一步】，进入标准库选择（默认推荐 **GB/T 7713.1-2006 学位论文通用规范**）。
3. **本地排版**：点击【✨ 开始一键极简排版】，观察 **Radial Gauge 环形动态进度仪表盘** 推进 4 个阶段（结构识别 $\rightarrow$ 样式计算 $\rightarrow$ 样式注入 $\rightarrow$ 完整性自审）。
4. **交付与 X-Ray 透视比对**：
   - 触发 Canvas 礼花粒子庆祝动效；
   - 查阅 4 项合规指标卡与人话排版亮点清单；
   - 左右拖拽 **X-Ray 透视比对滑块**，直观对比排版前后的字体、行距与首行缩进；
   - 点击【📥 下载排版后规范论文 (.docx)】获取真实排版生成的 Word 文档。

### 路径 B：详细与 Agent 智排工作台
1. 在页面顶部切换胶囊选择 **“⚡ 详细与 Agent 智排”**。
2. **段落级 Diff 审核**：查看每一处被修改的段落格式比对，支持逐项撤销或勾选。
3. **智能规范提炼**：在右侧控制台输入学校非标通知文本，点击【✨ Agent 智能提炼规范】，提取结构化规则草稿。
4. **深度 OOXML 攻坚**：开启“正文引注智能转页下真脚注”或“动态图表公式交叉引用域代码”。
5. **AI 盲审质检**：点击【🔍 启动 AI 盲审质检】，获取学术要素与文献规范的审查建议清单。
