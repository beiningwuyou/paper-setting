# 论文排版台 —— Agent-Native 学术级智能工作台（精简项目卡片）

### 📌 一句话定位
> 首个融合 **“双向 Agent 调度架构”** 与 **“人机安全回环 (HITL)”** 的出版级排版系统。既可通过 **MCP 标准协议** 赋能外部办公 Agent，也能在工作台内**直接唤醒本地大模型（DeepSeek / 腾讯 WorkBuddy）**反推格式并进行严谨排版。

---

### 💡 Agent 核心能力与技术亮点

1. **双向 Agent 协同中枢（MCP Server + Agent Client）**
   - **对外供调 (Server)**：向 Cursor、WorkBuddy、Trae 暴露 7 项底层排版工具；
   - **对内直调 (Client)**：用户无需跳出软件，在工作台内一键调度 DeepSeek 或本地离线引擎，自动解析高校杂乱的格式通知。

2. **国内主流 Agent 生态零门槛直连**
   - 自动扫描 Mac 本机已安装的 **腾讯 WorkBuddy、字节豆包、Trae、DeepSeek**；
   - 支持 **“一键免配置热写入 (`mcp.json`)”** 并自动安全备份，解决国内用户境外网络与繁琐配置痛点。

3. **思考过程可视化 + 100% 内容防幻觉安全回环 (HITL)**
   - **透明思考视窗**：在工作台内实时流式渲染 Agent 的决策推导链；
   - **安全回环底线**：Agent **只产出段落级 Diff 建议**，必须经人工勾选审查后才执行底层物理重排，杜绝 AI 偷改论文文字与丢图丢表的致命事故。

4. **100% 离线确定性纯算引擎**
   - 内置 0-Token 纯算规约底座，支持敏感与保密涉密论文在完全断网环境下安全重排。

---

### 🛠️ 技术栈与工程实践
- **前端与交互**：React 18 / Vite / Tailwind CSS / 动态思考流视窗
- **后端与调度**：Python 3.10+ / FastAPI / 策略模式多 Agent 调度适配器 / Model Context Protocol (MCP)
- **核心沙箱**：自研确定性 OOXML 物理排版引擎（真脚注、公式对齐、连续引用折叠）
- **客户端交付**：macOS 原生 Swift / AppKit / WKWebView 深度封装与代码签名（已交付 v1.1.3 原生 App）
